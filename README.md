# UNEMPLOYMENT_ANALYSIS_INDIA – Unemployment Trends & Insights Using Python🚶‍♂️💼
This repository showcases a data analysis project focused on examining India’s unemployment patterns (2019–2020) using Python. The project involves data cleaning, exploratory analysis, and advanced visualizations to uncover key insights into urban vs rural unemployment disparities and the economic impact of COVID-19.

# 📇 Project Overview

    • Dataset: Unemployment in India.csv — containing monthly unemployment rates, employment estimates, and labour participation data across 28 regions (May 2019 – Dec 2020).
    • Tools: Python (pandas, numpy, matplotlib, seaborn)
    • Focus Areas: Data cleaning, EDA, time-series visualization, correlation analysis, regional comparison, and policy-oriented recommendations.

# ╰┈➤ 📝 Steps Breakdown

    • Step 1: Loaded and cleaned the dataset — removed missing values, checked for duplicates, standardized column names, and prepared a structured dataframe.
    • Step 2: Conducted descriptive statistics to understand data distribution and identify regional differences between Rural and Urban areas.
    • Step 3: Created advanced visualizations —
      📈 Overall Unemployment Trend (Rolling Average)
      📉 Top 5 States Unemployment Trend
      🏙️ Rural vs Urban Comparison (Bar & Pie Chart)
      📦 Distribution Analysis (Box Plot)
      🧭Correlation Heatmap of Key Indicators
    • Step 4: Interpreted patterns showing a dramatic unemployment surge during April–May 2020, especially in urban regions, followed by a gradual recovery.
    • Step 5: Developed actionable recommendations to strengthen employment schemes, enhance skill development, and improve workforce participation.

# 🎯 Outcome
The analysis reveals clear evidence of COVID-19’s short-term economic disruption, with unemployment peaking near 35% nationally before recovery.
Urban regions consistently showed higher unemployment rates than rural ones.
The project concludes with data-driven policy recommendations emphasizing rural employment support, skill enhancement, and real-time labour data tracking.
